# Frontend Skeleton Project

A modern and responsive **React + TypeScript** frontend starter template built with **Vite** and **Tailwind CSS**. This project provides a clean, scalable foundation for developing web applications with reusable components, smooth animations, theme switching, and multiple pages.

---

## ✨ Features

- ⚛️ Multi-page React application
- 🧩 Reusable UI components
  - Navbar
  - Hero Section
  - Card Component
  - Footer
- 🧭 React Router based navigation
- 📱 Fully responsive and mobile-friendly layout
- 🎨 Built with Tailwind CSS
- 🌙 Dark Mode & ☀️ Light Mode support
- 💚 Modern White & Green color theme
- ✨ Smooth animations and transitions
- 🔐 Login page as the main entry component
- ℹ️ About page with website information
- 💬 Support page
- 👨‍💻 Enhanced footer with creator details and support links
- 🏗️ Component-based architecture for easy maintenance

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project directory

```bash
cd frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
