# ProductDescriptionAI

**ProductDescriptionAI** is an AI-powered product description manager that helps eCommerce businesses generate engaging, SEO-friendly, and conversion-focused product descriptions in seconds.

## 🚀 Features

* Generate product descriptions using AI
* Manage and organize product content
* Customize description tone and style
* SEO-friendly content generation
* Easy-to-use web interface

## ⚠️ Known Limitations (Free Tier)

- **Render Free Tier:** The backend service automatically spins down after approximately **15 minutes of inactivity**. The first request after the service has been idle may take **30–60 seconds** while the server wakes up.
- **Vercel Free Tier:** Subject to bandwidth and build limits suitable for development and small-scale deployments.
- **MongoDB Atlas Free Tier (M0):** Limited storage, shared cluster resources, and connection limits intended for development and testing.
- AI API usage may be subject to free-tier rate limits and daily quotas depending on the configured API provider.
