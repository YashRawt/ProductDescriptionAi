# ProductDescriptionAI

**ProductDescriptionAI** is an AI-powered product description manager that helps eCommerce businesses generate engaging, SEO-friendly, and conversion-focused product descriptions in seconds.

## 🚀 Features

* Generate product descriptions using AI
* Manage and organize product content
* Customize description tone and style
* SEO-friendly content generation
* Easy-to-use web interface

## 🛠 Tech Stack

### Frontend

* React
* Vite
* Tailwind CSS

### Backend

* Python
* FastAPI

### Database

* MongoDB Atlas

### AI Integration

* OpenAI API/Gemini
